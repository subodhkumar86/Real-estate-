# Real Estate

InvestInPro Noida is a premium real-estate advisory platform for curated residential and commercial properties across Noida and NCR.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Production

```bash
npm run build
npm start
```

## Features

- Curated property and project collections
- Location discovery and property comparison
- Wishlist, mortgage, and ROI tools
- Private vault and consultation enquiries
